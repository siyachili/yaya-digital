# Digital Leap — Iteration 01

A premium agency portfolio built with Next.js 14 and Tailwind CSS.

## Run locally

1. Install Node.js 20 LTS or newer.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

Open http://localhost:3000

## What changed in this iteration

- New animated editorial hero
- Real Digital Leap portfolio projects
- Scroll reveal motion using the browser Intersection Observer
- Interactive services accordion
- Stronger hover behaviour and responsive project layouts
- No additional animation libraries required

## Main editing points

- Hero copy: `components/Hero.jsx`
- Projects: `components/Work.jsx`
- Services: `components/Services.jsx`
- Global styling and motion: `app/globals.css`
